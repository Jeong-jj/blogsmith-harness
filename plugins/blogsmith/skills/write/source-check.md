# 소스 대조

`write` 8단계가 `audit.py` 를 끝낸 뒤 `source-checker` 를 띄우는 절차다.

## 왜 쓴 쪽에서 떼나

`audit.py` 는 **소스를 안 읽는 스크립트다.** 소스와 본문이 맞는지는 판정 범위 밖이다.
그래서 이 검사가 통째로 쓴 쪽의 자기 신고에 걸려 있었고, 그 신고가 두 판 연속으로 틀렸다.

```
1판   (천장이 생각보다 낮았어요)
2판   책장이 벽을 따라 둘러 서 있는데 / 버스로 가는 게 나아요 / 훑어보는 재미로
```

넷 다 소스에 0건인데 두 판의 `review.md` 는 근거가 있다고 적었다.
**틀린 것을 안 센 것이지 거짓을 적은 것이 아니다.** 기준이 자기 의도였다.

## 언제 띄우나

**`audit.py` 가 끝난 뒤다.** 1회차에서 멈췄든 3회를 다 돌았든 그 뒤다.

`audit.py` 가 고치면서 없는 서술을 넣을 수 있다. 뻔한 수식을 지우고 구체성을 채우는 수정이
소스에 없는 값을 끌어오는 자리다. **발행될 최종 본문을 검사해야 그것까지 걸린다.**

초안 직후에 띄우면 그 뒤 세 번의 수정이 검사 밖에 남는다.

## 무엇을 넘기나

```
notes.md 의 절대 경로
article.md 의 절대 경로
사진에서 읽은 값          photo-reader 가 낸 것을 그대로 붙인다
```

**본문을 프롬프트에 붙이지 않는다.** 경로를 주고 에이전트가 직접 읽는다.
붙이면 메인 대화에 본문 사본이 하나 더 생긴다.

**사진 값은 붙여서 넘긴다.** `review.md` 는 9단계에서 쓰므로 이 시점에 아직 없다.
빠뜨리면 메뉴판에서 읽은 가격이 전부 `근거 없음` 으로 올라온다.

**문체 문서와 지식 스킬을 넘기지 않는다.** 아웃라인과 초안의 경위도 넘기지 않는다.
넘기면 쓴 쪽과 같은 변호를 할 수 있게 되고 떼어낸 값이 사라진다.

## 받은 것을 어떻게 고치나

**고치는 방법이 둘로 제한된다.**

```
지운다        그 문장이나 그 구절을 뺀다
소스 값으로 바꾼다  notes.md 나 사진 값에 있는 것으로 교체한다
```

**새 서술을 지어 빈자리를 메우지 않는다.** 그러면 그 자리에 또 근거 없는 문장이 들어오고
검사는 이미 끝나 있다. 제한을 두는 대신 **다시 부르지 않는다.** 왕복이 한 번으로 끝난다.

갈래마다 할 일이 다르다.

| 갈래 | 할 일 |
|---|---|
| `근거 없음` | 지운다. 소스에 있는 값으로 바꿀 수 있으면 바꾼다 |
| `늘린 것` | 소스가 말하는 범위로 줄인다. `늘 차 있다` 를 `그날은 차 있었다` 로 |
| `어긋남` | 소스 값으로 바꾼다. 사진과 메모가 서로 다르면 사용자에게 넘긴다 |

**지워서 분량이 관찰 하한에 못 미치면 채우지 않는다.** 5단계와 같은 자리다.
짧게 두고 무엇이 모자랐는지 `못 지킨 것` 에 적는다.

**사용자에게 넘길 것은 `못 지킨 것` 에 적는다.**

```
[판단 필요]   자몽차 가격이 메모와 사진에서 다릅니다
[소스 부족]   책장 배치를 적으려면 사진 02 를 열거나 메모에 한 줄이 필요합니다
```

## `review.md` 에 어떻게 적나

**절을 새로 만들지 않는다.** 절 구성이 다섯으로 고정돼 있고, 늘면 두 판을 나란히 못 본다.

`스크립트로 안 되는 검사` 의 여섯째 줄을 **판정 결과로 쓴다.**

```
전   경험 서술의 근거: 웨이팅 20분과 콘센트 위치는 notes.md 에 있습니다
후   경험 서술의 근거: source-checker 3건 지적. 3건 삭제, 0건 남음
```

**쓴 쪽이 자기 근거를 나열하는 줄에서 다른 쪽의 판정을 적는 줄로 바뀐다.**
`audit.py` 절이 통과 여부와 회수만 남기는 것과 같은 형식이다.

**지적받은 내용을 이 줄에 적지 않는다.** 건수만 적는다.
사용자가 해야 할 일이 남았으면 그것은 `못 지킨 것` 에 있다.

**0건이면 0건이라고 적는다.** `지적 없음` 과 `안 돌렸음` 이 구분돼야 한다.

```
경험 서술의 근거: source-checker 0건 지적
```

## 두 플랫폼을 나란히 둘 때

**판마다 따로 띄운다.** 본문이 둘이고 각각이 검사 대상이다.

`alt` 만 다르고 본문이 같으면 결과도 같아야 한다. **다르게 나오면 본문이 갈린 것이다.**
`expected.md` 가 본문 `diff` 로 보는 자리와 같은 것을 가리킨다.
