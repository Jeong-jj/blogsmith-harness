# 산출물 형식

`output/<글감 폴더>/` 에 네 파일이 항상 나온다.

```
article.md    본문
photos.md     사진 순서, 위치, 캡션
meta.md       제목 후보, 태그, 메타 디스크립션, 발행 전 확인
review.md     audit 결과, 검색 노출 체크, 못 지킨 것
```

`meta.md` 는 발행할 때 보고 `review.md` 는 발행 전에 한 번 본다. 역할이 다르므로 나눈다.

---

## article.md

```markdown
---
source: 2026-08-03 성수동 카페
style: casual-review
platform: naver
created: 2026-08-13
---

# 성수동 코너스톤, 2층 창가가 정답이다

토요일 오후 2시에 갔다가
20분 기다렸다.

밖에 그늘이 없어서 좀 힘들었음.

![간판이 작아서 지나치기 쉽다](01_외관_간판작음.jpg)

## 2층 창가 자리를 노려라

1층은 시끄럽고 사람이 많다.
2층 창가가 비어 있어서 앉았는데

여기가 제일 낫다.

![2층 창가 자리](02_2층창가.jpg)

오후 3시쯤 빛이 들어오는데 사진 찍기 좋다.
```

frontmatter 에 무엇으로 썼는지 남긴다. 나중에 결과가 나쁘면 어느 문체였는지 추적할 수 있다.

### 컴포넌트가 아니라 역할대로 적는다

| 역할 | 표기 |
|---|---|
| 글 제목 | `#` |
| 대제목 | `##` |
| 소제목 | `###` |
| 진짜 인용 | `>` |
| 구분선 | `---` |
| 굵게 | `**` |

**대제목을 인용 블록으로 쓰는 문체라도 `##` 로 적는다.**
의미상 제목인 것을 `>` 로 표시하면 마크다운으로서 틀리고,
티스토리와 velog 에서 제목이 인용문 상자로 렌더된다.
네이버에서는 어느 기호든 텍스트로 남아 사용자가 지워야 하므로 얻는 것도 없다.

어느 컴포넌트로 만들지는 `meta.md` 의 발행 전 확인이 안내한다.

### 문단 안 줄바꿈

위 예시는 `platform: naver` 라 개행만 있다. 플랫폼마다 표기가 갈린다.

```
naver                         tistory / velog / markdown

토요일 오후 2시에 갔다가       토요일 오후 2시에 갔다가··
20분 기다렸다.                 20분 기다렸다.
```

`··` 는 공백 두 칸이다. 마크다운은 개행 하나를 줄바꿈으로 보지 않아서
공백이 없으면 `토요일 오후 2시에 갔다가 20분 기다렸다.` 한 줄이 된다.

네이버는 붙여넣기에서 개행이 줄바꿈으로 살아남는다.
PC 웹 스마트에디터 ONE 과 모바일 앱 둘 다 확인했다. 그래서 공백을 넣지 않는다.

**백슬래시는 쓰지 않는다.** 한글 폰트에서 `₩` 로 렌더되어 본문에 그대로 남는다.

문단 안의 빈 줄은 플랫폼과 무관하게 빈 줄이다.
`2층 창가가 비어 있어서 앉았는데` 와 `여기가 제일 낫다.` 사이가 그 자리다.

**`naver` 로 만든 파일을 마크다운 미리보기로 열면 줄이 합쳐져 보인다.**
`article.md` 는 붙여넣기용 중간 산출물이고 렌더 대상이 아니다.
합쳐져 보이는 것과 붙여넣었을 때 나뉘는 것은 다르다.

```markdown
캡션은 그대로 복사해 쓰시면 됩니다.

| 2 | `02_2층창가.jpg` | "2층 창가 자리를 노려라" 첫 문단 뒤 | 2층 창가 자리 |

sources/2026-08-03 성수동 카페/

`.HEIC` 파일은 같은 폴더에 `.jpg` 로 변환해 두었습니다.

## 플랫폼 메모
```

본문에도 사진 자리가 표시되므로 표는 순서와 캡션을 한눈에 보는 용도다.
플랫폼 메모는 문체 문서에 관련 규칙이 있을 때만 쓴다.

## meta.md

```markdown
# 메타

## 제목

**선택**: 성수동 코너스톤, 2층 창가가 정답이다

후보
1. 성수동 코너스톤, 2층 창가가 정답이다
2. 웨이팅 20분 감수할 만한 성수동 카페
3. 성수동 코너스톤 후기 (주차 안 됨 주의)

## 태그

성수동카페 성수동코너스톤 서울숲카페 연무장길 성수동콜드브루
성수동디저트 서울숲카페추천 성수동브런치 코너스톤 성수동핫플
...

30개까지 뽑았습니다. 이 중에서 골라 쓰세요.

## 메타 디스크립션

> 성수동 코너스톤 방문 후기. 2층 창가 자리가 가장 좋고 콜드브루는 산미가 강한 편이다.
> 주차는 안 되고 콘센트는 2층에만 있다. 콜드브루 6,500원.

## 본문 표시 읽는 법

article.md 에 붙은 기호입니다. 에디터에 붙여넣은 뒤 지우고 서식으로 바꾸세요.

  #    글 제목        ##   대제목        ###  소제목
  >    인용           ---  구분선        **   굵게
  ![캡션](파일명)  사진 자리

## 발행 전 확인

- 사진 4장을 에디터에서 업로드 (`photos.md` 순서대로)
- `##` 대제목 1개를 **인용 컴포넌트**로 지정
- 영업시간이 바뀌지 않았는지 확인 (2026년 8월 기준)
```

메타 디스크립션은 구글 색인이 되는 플랫폼에서만 쓴다.
네이버 전용이면 생략해도 된다.

**`본문 표시 읽는 법` 은 마크다운을 모르는 사용자를 위한 범례다.**
`article.md` 안에 넣으면 붙여넣을 때 딸려가므로 여기 둔다.

개수는 실제 문서에 있는 만큼 적는다. 위 예시는 대제목이 하나뿐이라 한 줄이다.
소제목과 구분선이 있으면 같은 형식으로 줄을 더한다.

**어느 컴포넌트로 지정할지는 문체 문서의 `플랫폼 종속 규칙` 이 정한다.**
대제목을 인용 컴포넌트로 만드는 것은 그 블로거의 습관이지 공통 규칙이 아니다.
다른 문체를 학습하면 소제목 컴포넌트일 수도 있다. 문체 문서를 보고 적는다.

---


```

## 검색 노출 체크

플랫폼: naver

- [x] 1인칭 경험 서술
- [x] 사실 정보가 전부 소스에 근거
- [x] 소제목이 각각 하나의 질문에 답함
- [x] 단점 언급 (산미, 주차, 콘센트)
- [x] 제목에 키워드 나열 없음
- [x] 숫자와 고유명사 (가격 3종, 시간, 거리)
- [x] AI 생성 패턴 없음

## 스크립트로 안 되는 검사

`audit.py` 가 판정하지 못해 읽고 판단한 항목입니다. 한 줄씩 답을 적습니다.

- 소리 내어 읽기: 걸리는 곳 없음
- 형용사 지워보기: `아늑한` 을 지우니 뜻이 안 남아 `천장이 낮아 소리가 안 울린다` 로 바꿨습니다
- 첫 문단의 숫자와 고유명사: `성수동 코너스톤`, `토요일 오후 2시`, `20분` 이 있습니다
- 견해와 단점: `작업하러 가기엔 애매하다`, 주차 불가를 적었습니다
- 문단마다 요약 문장: 없습니다
- 경험 서술의 근거: 웨이팅 20분과 콘센트 위치는 `notes.md` 에 있습니다

## 못 지킨 것

없음
```

**왜 못 지켰는지를 함께 쓴다.** 그냥 항목만 적으면 사용자가 판단을 못 한다.

- 규칙 충돌: 어느 규칙과 부딪혔는지
- 소스 부족: 무엇이 없어서인지
- 판단 필요: 사용자가 정해야 할 것

`audit.py` 가 3회 안에 통과하지 못했으면 남은 항목을 여기에 적는다.

```
[편차] 문장 길이 변동계수 0.31 (하한 0.35)
   문체 문서 규칙 3 "문장을 35자 안에서 끝낸다" 와 충돌합니다.
   문체 문서를 따랐습니다.

[어휘] 얼버무린 출처 1건 ['일반적으로']
   "일반적으로 웨이팅이 있다" 문장입니다.
   소스에 근거 수치가 없어 못 고쳤습니다. 실제 대기 시간을 아시면 넣어주세요.
```
