# 네이버 검색 노출

조사 시점 2026-08-07.

## 근거 등급

네이버는 랭킹 로직을 공개하지 않는다. 아래 항목마다 등급을 붙였다.

| 등급 | 뜻 |
|---|---|
| `공식` | 네이버가 직접 밝힌 것 |
| `관찰` | 실무자 다수가 일관되게 보고하는 것 |
| `추정` | 출처마다 값이 갈리는 것 |

`추정`은 규칙으로 강제하지 않는다. 판단 재료로만 쓴다.

## 두 개의 축

네이버는 **누가 썼는가**와 **무엇을 썼는가**를 따로 본다.

**C-Rank (출처)** `공식`
블로그 자체의 신뢰도다. 특정 주제에 얼마나 깊이 있게, 꾸준히 쓰는지를 본다.
글 한 편으로 바뀌지 않는다. 주제를 흩뜨리면 떨어진다.

**D.I.A.+ (문서)** `공식`
개별 글의 품질이다. 키워드 적합도, 경험 정보, 정보 충실성,
어뷰징 척도, 독창성, 적시성을 복합 반영한다.

우리가 글 한 편으로 움직일 수 있는 것은 D.I.A.+ 쪽이다.
C-Rank는 사용자에게 "주제를 좁혀서 꾸준히 쓰라"고 안내할 수는 있어도 글로 만들 수 없다.

## 2026년에 바뀐 것

이게 가장 중요하다. 검색 순위 게임이 인용 게임으로 옮겨가는 중이다.

| 사건 | 시점 |
|---|---|
| AI 사이트 브리핑 도입 | 2025-12 |
| 연관검색어 서비스 종료 | 2026-04-30 |
| AI 브리핑 이용자 3천만, 전체 쿼리의 약 20% 처리 | 2026-04 |
| AI탭 정식 출시 | 2026-06-26 |
| 네이버 메이트 베타. **AI 브리핑 인용 횟수로 보상** | 2026-06-04 |

AI 브리핑 답변의 약 70%가 네이버 자사 UGC(블로그, 카페)에서 나온다. `관찰`

첫 화면이 AI 요약으로 채워지면서 순위에 들어도 클릭이 안 온다.
**목표가 "1위에 뜨는 것"에서 "AI가 내 글을 근거로 가져다 쓰는 것"으로 이동했다.**

실무적으로는 이렇게 바뀐다.

- 질문 하나에 대한 완결된 답을 소제목 단위로 만든다. AI가 문단째로 뽑아 쓴다
- AI가 만들어낼 수 없는 것을 넣는다. 실제 경험, 직접 찍은 사진, 확인한 숫자
- 백과사전식 나열은 AI 브리핑에 자리를 내준다

## 문서를 쓸 때

**경험 정보를 앞에 둔다.** D.I.A.+가 명시적으로 보는 항목이고,
AI가 생성할 수 없는 유일한 재료다.
"갔더니 웨이팅 20분", "산미가 강해서 호불호 갈림" 같은 1인칭 관찰이다.

**사실 정보를 지어내지 않는다.** 가격, 주소, 영업시간, 날짜는 소스에 있는 것만 쓴다.
없으면 비워두고 사용자에게 묻는다. 틀린 사실 하나가 문서 전체 신뢰도를 깎는다.

**소제목마다 하나의 질문에 답한다.** 스캔 가능성과 AI 추출 가능성이 같이 올라간다.

**단점을 쓴다.** 장점만 있는 글은 광고로 읽힌다.
"이런 사람에게는 안 맞는다"가 들어가면 신뢰도가 올라간다.

**제목은 짧고 명확하게.** 키워드를 나열하면 전문성이 낮아 보인다. `공식`
메인 키워드는 앞쪽에, 반복은 1~2회까지.

## 하지 말 것

**자동 생성 패턴을 남기지 않는다.** 네이버는
"자동 포스팅 프로그램으로 작성된 문서는 특유의 패턴을 보이며,
이를 감지하는 시스템에 의해 검색결과에서 제외된다"고 밝혔다. `공식`

**이 하네스에서 가장 중요한 제약이다.** AI가 쓴 티가 나면 노출이 안 되는 정도가 아니라
아예 제외된다.

최소한 이것들은 피한다.

- 문장 길이가 전부 비슷한 것
- 문단마다 끝에 요약을 붙이는 것
- 항목 수를 3개로 맞추는 것
- "결론적으로", "정리하자면" 같은 마무리 상투구
- em dash 남용, 볼드 남발
- 번역투: `~에 대한`, `~을 통해`, `~라고 할 수 있습니다`

이것만으로는 부족하다. 문체 규칙 전체는 `natural-voice` 스킬로 분리할 예정이다.
그 전까지는 학습한 문체 문서(`styles/`)의 재현 규칙을 우선 따른다.
사람의 실제 문체를 따라가면 자동 생성 패턴은 자연히 사라진다.

나머지 금지 항목.

- 키워드 도배, 숨김 텍스트로 키워드 채우기
- 다른 글 복사, 자기 글 재탕 (유사문서 판정)
- 과도한 외부 링크, 쇼핑몰 링크 나열
- 주제와 무관한 이슈 키워드 올라타기. C-Rank가 떨어진다 `공식`
- 공감, 댓글, 이웃 수 조작

저품질 판정은 한 번 받으면 회복이 오래 걸린다. 경계선에서 놀지 않는다.

## 수치 기준

출처마다 값이 갈린다. 전부 `추정`이다. 범위로만 쓰고 목표치로 삼지 않는다.

| 항목 | 보고된 범위 |
|---|---|
| 본문 길이 | 800~2,000자 |
| 문단 길이 | 3~4줄 이하 |
| 이미지 | 5~13장 |
| 메인 키워드 반복 | 3~5회 |
| 내부 링크 | 2~3개 |

**글자 수를 목표로 쓰지 않는다.** 필요한 내용을 다 쓰면 자연히 그 범위에 든다.
분량을 채우려고 늘리면 D.I.A.+의 어뷰징 척도와 독창성 항목에서 손해다.

직접 찍은 사진이 스톡 이미지보다 낫다는 것은 여러 출처가 일치한다. `관찰`

## 스마트블록

검색 결과가 주제별 블록으로 나뉜다. 같은 1페이지여도 어느 블록이냐로 클릭률이 갈린다. `관찰`

블록별로 노리는 것이 다르다.

| 블록 | 유리한 조건 |
|---|---|
| 인기 주제 | 발행 직후 반응(체류, 공감, 댓글), 시의성 |
| AI 추천 | 정확한 정보, 체계적 구조, 출처 명시 |
| 지식 스니펫 | 질문형 제목과 그에 대한 직접적인 답 |
| 플레이스 | 지역명, 업체명, 방문 정보 |

지역 소재 글이면 지역명과 업체 정보를 본문에 정확히 넣어 플레이스 블록을 같이 노린다.

## 검토 체크리스트

글을 넘기기 전에 확인한다.

- [ ] 1인칭 경험 서술이 있는가
- [ ] 사실 정보가 전부 소스에 근거하는가
- [ ] 소제목이 각각 하나의 질문에 답하는가
- [ ] 단점이나 한계가 언급되는가
- [ ] 제목에 키워드가 나열되어 있지 않은가
- [ ] AI 생성 패턴이 없는가 (문장 길이, 항목 수, 마무리 상투구)
- [ ] 분량을 채우려고 늘린 문단이 없는가
