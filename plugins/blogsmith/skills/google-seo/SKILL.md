# 구글 검색 노출

조사 시점 2026-08-07. 근거는 대부분 구글 공식 문서다.
네이버와 달리 구글은 기준을 문서로 공개한다. 추측할 필요가 없다.

적용 대상은 티스토리, velog, 개인 도메인이다.
네이버 블로그는 구글 색인이 제한적이라 `naver-seo`를 우선한다.

## Who, How, Why

구글이 콘텐츠를 판단하는 세 질문이다. 순서대로 자문한다.

**Who.** 누가 썼는지 드러나는가.
저자명, 저자의 배경, 그 주제를 다룰 자격이 페이지에 보여야 한다.

**How.** 어떻게 만들었는지 투명한가.
직접 써봤다면 무엇을 얼마나 테스트했는지, 사진 같은 증거가 있는지.

여기에 우리에게 직접 걸리는 항목이 있다.
구글은 **"자동화나 AI 사용이 명확하게 공개되는가"**를 묻는다.
그리고 **"검색 순위 조작을 위해 AI로 대량 생산하는 것은 스팸 정책 위반"**이라고 못 박았다.

AI로 초안을 만들었다면 사람이 검증하고 자기 경험을 넣어야 한다.
그 과정 없이 그대로 발행하면 정책 위반 쪽에 가깝다.

**Why.** 왜 만들었는가. 이게 가장 중요하다.
사람을 돕기 위해서인가, 검색 유입을 위해서인가.
후자면 나머지를 아무리 잘해도 구글은 걸러낸다.

## E-E-A-T

Experience(경험), Expertise(전문성), Authoritativeness(권위), Trustworthiness(신뢰).

**신뢰가 중심이고 나머지 셋이 그것을 뒷받침한다.** 넷을 다 보일 필요는 없다.

가장 만들기 쉬운 것이 Experience다. 직접 해본 사람의 서술은 대체 불가능하다.
전문 자격이 없어도 실제로 써보고 가보고 겪은 것은 쓸 수 있다.

**YMYL** 주제는 기준이 올라간다. 건강, 재정, 안전, 법률처럼
사람의 삶에 영향을 주는 분야다. 이 영역 글은 출처와 근거를 훨씬 엄격하게 요구한다.
자격 없이 단정하지 않는다. 확인 가능한 출처를 링크한다.

E-E-A-T 자체는 랭킹 요소가 아니다. 그것을 식별하는 신호들의 조합이 순위에 영향을 준다.

## 자가진단

구글이 제시한 질문들이다. 글을 넘기기 전에 걸어본다.

**독창성**
- 독자적인 정보, 취재, 연구, 분석이 있는가
- 뻔한 것 이상의 통찰이 있는가
- 다른 출처를 인용할 때 상당한 추가 가치를 더하는가

**완성도**
- 주제를 실질적이고 포괄적으로 다루는가
- 서둘러 만든 티가 나는가
- 쉽게 확인되는 사실 오류가 없는가

**독자**
- 의도한 독자가 직접 찾아왔을 때 유용한가
- 목표를 달성하고 떠나는가, 다른 곳을 더 찾아봐야 하는가

## 하지 말 것

구글이 명시한 경고 신호다.

- 검색 유입을 주목적으로 제작
- 광범위한 자동화로 많은 주제의 콘텐츠 대량 생산
- 다른 출처를 실질적 개선 없이 요약
- 유기적 관심 없이 트렌드만 쫓기
- **특정 단어 수를 목표로 작성.** 구글에는 선호 단어 수가 없다
- 실제 전문성 없이 틈새 주제 진입
- 페이지 날짜만 바꿔 신선함 위장
- 순위 개선 목적의 대량 추가나 삭제

세 번째와 다섯 번째가 우리에게 특히 위험하다.
소스가 빈약한데 분량을 채우려 들면 정확히 이 함정에 빠진다.

## 문서 구조

**제목은 명확하고 설명적으로.** 과장하지 않는다.
`h1`은 하나, 소제목은 `h2`와 `h3`로 계층을 지킨다.

**단락, 섹션, 제목으로 명확히 구성한다.** 구글 공식 권고다.
사람이 읽기 좋은 구조가 곧 기계가 이해하기 좋은 구조다.

**이미지와 영상을 넣는다.** alt 텍스트를 채운다.

## AI 검색 기능 최적화

구글이 2026년에 공식 가이드를 냈다. 요지는 **별도 전략이 필요 없다**는 것이다.

구글이 **불필요하다고 명시한 것들**이다.

| 항목 | 구글 입장 |
|---|---|
| `llms.txt` 같은 AI 전용 파일 | 무시한다. 만들지 마라 |
| 콘텐츠를 작은 조각으로 쪼개기(chunking) | 불필요. 한 페이지의 여러 주제를 이해한다 |
| AI만을 위한 문체 변경, 롱테일 키워드 의존 | 불필요. 동의어와 의미를 이해한다 |
| Schema.org 마크업 | 필수 아님. SEO 전략의 일부로만 유용 |
| 인위적 브랜드 언급 만들기 | 효과 없음. 스팸 정책 위반 |
| 제3자 "GEO 최적화" 서비스 | 주의 |

**단, 이건 구글의 AI 기능에 한한 말이다.**
ChatGPT나 Perplexity는 자체 수집 경로를 쓰므로 다르게 움직인다.
그쪽은 `geo-aeo`를 참조한다.

## 검토 체크리스트

- [ ] 저자와 그 근거가 드러나는가
- [ ] AI로 만든 부분을 사람이 검증하고 경험을 더했는가
- [ ] 검색 유입이 아니라 독자를 위해 쓴 글인가
- [ ] 직접 경험이 들어갔는가
- [ ] YMYL 주제라면 출처를 링크했는가
- [ ] 분량을 맞추려고 늘린 곳이 없는가
- [ ] `h1` 하나, 소제목 계층이 지켜지는가
- [ ] 이미지 alt 텍스트가 채워졌는가
