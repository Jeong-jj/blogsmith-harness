# sources

아티클의 원천 자료를 넣는 곳입니다. 글감 하나당 디렉토리 하나를 만드세요.

```
sources/
├── _sample/              형식 예시입니다. 지우지 말고 참고하세요
├── 2026-08-성수동카페/
│   ├── notes.md          겪은 일과 넣고 싶은 정보
│   ├── photo-01.jpg
│   └── photo-02.jpg
└── 2026-08-이사후기/
    └── notes.md
```

## notes.md

형식은 `_sample/notes.md`를 보세요. 문장을 다듬을 필요는 없습니다.
기억나는 대로, 순서 없이 적어도 됩니다. 정리는 blogsmith가 합니다.

빠뜨리면 안 되는 것은 두 가지입니다.

- **사실 정보**: 가격, 주소, 영업시간, 날짜처럼 지어낼 수 없는 값
- **본인이 실제로 겪은 것**: 검색 노출에서 경험 기반 서술이 가장 크게 작동합니다

## 사진

파일명은 아무래도 좋지만 `notes.md`에서 언급하면 배치가 정확해집니다.
사진에 담긴 정보(간판의 가격표, 메뉴판)는 blogsmith가 읽어서 씁니다.

## 커밋

이 디렉토리는 `.gitignore`로 내용물이 제외됩니다. `README.md`와 `_sample/`만 남습니다.
개인 사진과 메모가 저장소에 올라가지 않게 하려는 설정입니다.
