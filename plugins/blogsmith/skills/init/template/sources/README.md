# sources

> 이 문서는 blogsmith 가 제공하는 안내입니다.
> 고쳐도 `/blogsmith:update` 가 최신 내용으로 덮어씁니다.
> 적어둘 것이 있으면 `notes.md` 나 별도 파일에 쓰세요.

아티클의 원천 자료를 넣는 곳입니다. 글감 하나당 폴더 하나를 만드세요.

```
sources/
├── _sample/                     형식 예시입니다. 다 보셨으면 지우셔도 됩니다
├── 2026-08-03 성수동 카페/
│   ├── notes.md                 겪은 일과 넣고 싶은 정보
│   ├── 01_외관_간판작음.jpg
│   └── 02_2층창가.jpg
└── 2026-08-10 제주도 여행/
    └── notes.md
```

폴더 이름은 자유입니다. 띄어쓰기나 한글이 들어가도 됩니다.
날짜를 앞에 붙이면 Finder에서 시간순으로 정렬돼서 찾기 편합니다.

## notes.md

형식은 `_sample/notes.md`를 보세요. 문장을 다듬을 필요는 없습니다.
기억나는 대로, 순서 없이 적어도 됩니다. 정리는 blogsmith가 합니다.

빠뜨리면 안 되는 것은 두 가지입니다.

- **사실 정보**: 가격, 주소, 영업시간, 날짜처럼 지어낼 수 없는 값
- **본인이 실제로 겪은 것**: 검색 노출에서 경험 기반 서술이 가장 크게 작동합니다

## 사진

**파일명이 아티클에 그대로 쓰입니다.** 사진 설명을 만드는 재료가 되니까요.

```
IMG_4821.jpg              아무 정보가 없습니다. 본문에 활용하지 못합니다
외관.jpg                  위치는 압니다
01_외관_간판작음.jpg        순서와 캡션이 한 번에 나옵니다
```

아이폰에서 옮긴 사진은 `.HEIC`입니다. blogsmith가 알아서 JPG로 바꾸니 그대로 두셔도 됩니다.

### 어떤 사진을 읽을지

**`notes.md`의 사진 메모에서 `[읽기]`를 붙인 사진만 열어봅니다.**

```
- 04_메뉴판.jpg [읽기]
```

메뉴판 가격, 간판 영업시간, 영수증 금액처럼 **파일명만으로는 알 수 없는 것**에만 붙이세요.
음식이나 풍경 사진은 파일명으로 충분합니다.

사진 한 장을 여는 데 토큰이 꽤 듭니다. 열 장을 다 열면 본문보다 사진이 더 비쌉니다.
그래서 기본은 안 여는 쪽이고 필요한 것만 골라 붙이는 방식입니다.

**표시를 빠뜨리면 그 사진은 안 열립니다.** 사진 안의 정보가 본문에 안 들어갑니다.
붙이고 다시 돌리시면 됩니다.

전체를 한꺼번에 정하려면 `blog.config.json`의 `imageMode`를 씁니다.

| 값 | 동작 |
|---|---|
| `filename` | `[읽기]`가 붙은 사진만 엽니다. 기본값 |
| `read` | 표시와 무관하게 전부 엽니다 |
| `ask` | `[읽기]`가 붙은 사진을 열기 전에 목록을 보여주고 확인받습니다 |

## 사진은 직접 올리셔야 합니다

blogsmith는 사진을 블로그에 업로드하지 못합니다.
네이버, 티스토리, velog 모두 에디터에 로그인해서 올려야 합니다.

대신 **어느 자리에 어떤 사진이 들어가는지 표시하고 캡션 문구를 만들어 둡니다.**
완성된 아티클과 함께 `output/<글감>/사진배치.md`가 나오니 그걸 보고 올리시면 됩니다.
