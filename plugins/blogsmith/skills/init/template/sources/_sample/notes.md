# 성수동 카페 다녀옴

정리 안 해도 됩니다. 생각나는 대로 적으세요.
아래 소제목은 참고용이고, 없어도 되고 더 만들어도 됩니다.

이 폴더는 형식을 보여주는 예시입니다. 다 보셨으면 지우셔도 됩니다.

## 언제 어디서

- 2026년 8월 3일 토요일 오후 2시쯤
- 성수동 연무장길, 카페 이름은 "코너스톤"
- 서울숲역 3번 출구에서 걸어서 7분

## 무슨 일이 있었나

주말이라 웨이팅 20분 정도 했다. 밖에서 기다리는데 그늘이 없어서 힘들었음.
2층 창가 자리가 비어서 앉았는데 여기가 제일 좋은 자리인 듯.
1층은 시끄럽고 사람 많다.

콜드브루 시켰는데 산미가 강한 편. 나는 좋았는데 산미 싫어하면 비추.
같이 간 친구는 아인슈페너 시켰고 그건 무난했다.

## 사실 정보

- 콜드브루 6,500원 / 아인슈페너 7,000원 / 크로플 8,000원
- 영업시간 11:00 ~ 21:00, 매주 월요일 휴무
- 주차 불가. 근처 공영주차장 도보 5분
- 콘센트는 2층에만 있음

## 느낀 점, 하고 싶은 말

작업하러 가기엔 애매하다. 콘센트가 적고 2시간 제한이 있음.
사진 찍으러 가기엔 좋다. 특히 오후 3시쯤 2층 창가 빛이 예쁨.
재방문 의사는 있는데 평일에 갈 것 같다.
