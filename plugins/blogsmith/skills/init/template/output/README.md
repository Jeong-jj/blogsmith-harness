# output

완성된 아티클이 저장되는 곳입니다. 글감 하나당 폴더 하나가 생깁니다.

```
output/
└── 2026-08-03 성수동 카페/
    ├── article.md         마크다운 원본
    ├── naver.txt          네이버 블로그 붙여넣기용
    ├── 사진배치.md         어느 자리에 어떤 사진을 넣는지
    └── meta.md            제목 후보, 태그, 검색 노출 메모
```

플랫폼은 글을 쓸 때 고릅니다.

```
/blogsmith:write "2026-08-03 성수동 카페" --platform naver
```

지원 값은 `markdown`, `naver`, `tistory`, `velog`입니다.
`blog.config.json`의 `defaultPlatform`으로 기본값을 정할 수 있습니다.

## 사진은 직접 올리셔야 합니다

blogsmith는 사진을 블로그에 업로드하지 못합니다.
네이버, 티스토리, velog 모두 에디터에 로그인해서 올려야 합니다.

`사진배치.md`에 순서와 캡션이 정리되어 나옵니다.
에디터에 본문을 붙여 넣고, 표시된 자리에서 사진 버튼을 눌러 올리시면 됩니다.
캡션 문구는 그대로 복사해 쓰시면 됩니다.
