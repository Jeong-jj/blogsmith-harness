# styles

> 이 문서는 blogsmith 가 제공하는 안내입니다.
> 고쳐도 `/blogsmith:update` 가 최신 내용으로 덮어씁니다.
> 적어둘 것이 있으면 `notes.md` 나 별도 파일에 쓰세요.

학습한 문체 문서가 저장되는 곳입니다.

`/blogsmith:learn-style`에 블로그 글 주소를 주면 그 글들을 읽고
문장 길이, 어미, 소제목 배치, 사진과 글의 비율, 도입부와 마무리 습관을 분석해서
규칙 문서로 만들어 여기에 저장합니다.

```
styles/
├── casual-review.md      친근한 후기체
├── info-dense.md         정보 위주 정리체
└── storytelling.md       서사 중심
```

## 쓰는 법

글을 쓸 때 스타일 이름으로 지정합니다.

```
/blogsmith:write "2026-08-03 성수동 카페" --style casual-review
```

`blog.config.json`의 `defaultStyle`에 이름을 적어두면 생략할 수 있습니다.

## 자동으로 못 읽는 경우

플랫폼에 따라 자동 수집이 막힐 수 있습니다.
blogsmith는 신분을 밝히고 요청하며, 거절당하면 우회하지 않습니다.

그때는 본문을 복사하거나 캡처해서 `styles/_raw/<이름>/`에 넣고 다시 실행하세요.

```
styles/_raw/내문체/
├── 01.txt      본문을 복사해 붙여넣기
└── 02.png      화면을 캡처한 이미지
```

텍스트가 이미지보다 정확하고 쌉니다. 이미지는 긴 글이면 여러 장이 필요합니다.

**여기에 넣은 파일은 원문 복제본입니다.**
본인이 쓴 글이면 마음껏 두셔도 됩니다.
다른 사람의 글이라면 문체 분석이 끝난 뒤 지우시는 편이 좋습니다.
`learn-style`이 분석을 마치면 삭제할지 물어봅니다.

## 여러 개를 만들어 두세요

맛집 후기와 제품 리뷰와 여행기가 같은 문체일 이유가 없습니다.

몇 개를 만들어 두고 글마다 골라 쓰는 편이 낫습니다.
