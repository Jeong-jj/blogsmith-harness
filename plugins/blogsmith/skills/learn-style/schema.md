# 문체 문서 스키마

`styles/<이름>.md`의 형식이다. `style-analyst`가 이 형식으로 쓰고 `write`가 읽는다.

## 쓰기 전에 읽을 것

**측정값과 명령형으로 채운다.** 형용사로 채우면 `write`가 재현할 수 없다.

**관찰한 편수를 항목마다 `(5/5)` 형태로 붙인다.**

**빈칸을 남기지 않는다.** 판단이 안 서면 `learn-style`이 사용자에게 물어서 채운다.
표본이 적다는 이유로 미루지 않는다.

### 관찰을 규칙으로 옮길 때

가장 자주 틀리는 지점이다. 세 가지를 지킨다.

**수치는 관찰 범위를 벗어나지 않는다.**
관찰이 `2~17%`면 상한은 `17%`다. `20%`로 잡으면 관찰보다 느슨해서 제약이 아니다.

**평균을 상한으로 쓰지 않는다.**
`평균 35자`를 `35자 안에서 끝낸다`로 바꾸면 편차가 사라진다.
관찰에 `편차 큼`이라고 써놓고 규칙이 편차를 없애면 앞뒤가 안 맞는다.
평균은 평균으로, 범위는 범위로 쓴다.

**소스에 의존하는 값은 절대 수치로 쓰지 않는다.**
사진 장수처럼 사용자가 가진 재료에 달린 것은 비율이나 조건으로 표현한다.
`한 편에 8~20장`은 사진이 3장뿐인 사용자가 지킬 수 없는 규칙이다.

```markdown

name: <스타일 이름>

- 독자 호칭:
- 말투:
- 거리감:

## 문장

- 종결어미:
- 평균 길이:
- 길이 편차:
- 줄바꿈 기준:

## 어휘

- 반복 표현:
- 입버릇과 감탄사:
- 이모지:
- 쓰지 않는 것:

## 구조

- 도입부:
- 소제목:
- 문단 길이:
- 마무리:

## 사진

- 글 대비 비율:
- 배치:
- 캡션:
- 언급 방식:

## 정보 밀도

- 사실 정보 위치:
- 표현 방식:

## 재현 규칙

<20개를 넘기지 않는다. 중요한 순서로 정렬한다.>
<1~10번은 필수. 하나라도 깨지면 그 사람 글이 아니다.>
<11~20번은 선택. 지키면 더 가까워진다.>
<충돌하면 번호가 작은 쪽을 따른다.>

   예) <실제 글에서 뽑은 짧은 형태>

2. ...

<해당 플랫폼이 아니면 건너뛴다. 없으면 "없음".>

- <플랫폼>: <규칙>

## 하지 말 것

<이 사람이 쓰지 않는 것. 여기가 비면 스타일이 뭉개진다.>
<0회라는 근거를 함께 적는다.>

-
-

## 근거 발췌

<한 문장씩 10개. 출처 URL 을 함께 적는다.>
<write 는 이 섹션을 읽지 않는다. 사람이 판단을 검증할 때 쓴다.>

> <문장>
> 출처: <URL>
```

---

## 재현 규칙 쓰는 법

### 지시문이어야 한다

**나쁨**

```
1. 친근하게 쓴다
2. 사진을 적절히 배치한다
3. 정보를 잘 정리한다
```

무엇을 해야 할지 알 수 없다. `write`가 이 문장으로 재현할 수 있는 것이 없다.

**좋음**

```
1. 해요체로 쓴다. 합니다체를 섞지 않는다.
   예) "여기 진짜 좋았어요" (O) / "이곳은 훌륭했습니다" (X)

2. 문단은 1~2줄로 만든다. 3줄을 넘기지 않는다.
   예) 두 문장 쓰고 빈 줄, 다시 두 문장

3. 사진은 소제목 바로 아래에 놓고, 설명은 사진 다음 문단에 쓴다.
   예) 소제목 > 사진 > "보다시피 천장이 낮다"
```

### 예시가 없으면 안 된다

각 규칙에 **실제 글에서 뽑은 짧은 형태**를 붙인다.
예시가 없으면 무슨 말인지 모르는 규칙이 섞인다.

```
나쁨   6. 소제목을 2단으로 짠다
좋음   6. 소제목을 2단으로 짠다. 큰 덩어리에 대제목, 그 안을 소제목으로 나눈다.
          예) 대제목 "호텔 조식 이용 후기" 아래에 소제목 "뷔페 음식 배치"
```

### 조건이 붙으면 조건을 먼저 쓴다

한 규칙이 상황에 따라 갈리면 나누지 말고 조건으로 묶는다.

```
14. 장소를 소개할 때 지도를 붙인다.
    국내면 네이버 지도 카드를 소제목 아래에 놓는다.
    해외면 지도 카드가 생성되지 않으므로 구글 지도 링크 카드를 쓴다.
    예) 국내 "성수동 코너스톤" 지도 카드 / 해외 구글 지도 링크
```

### 플랫폼 종속 규칙은 따로 뺀다

구분선, 링크 카드, 스티커처럼 **특정 에디터에서만 되는 것**은
`재현 규칙`이 아니라 `플랫폼 종속 규칙`에 넣는다.

`write`가 `--platform velog`로 돌 때 네이버 전용 규칙을 지키려다 이상해지는 것을 막는다.
