# Blogsmith

블로그 문체를 학습해 저장하고, 사진과 메모를 원천으로 아티클을 쓰는 Claude Code 플러그인입니다.

```
/blogsmith:learn-style https://blog.naver.com/example    문체를 분석해 규칙 문서로 저장
/blogsmith:write 2026-08-성수동카페 --style casual        저장한 문체로 아티클 작성
```

## 왜 앱이 아니라 하네스인가

같은 기능을 웹 서비스나 CLI 앱으로 만들면 사용자마다 API 키가 필요하고 토큰 비용을 직접 부담해야 합니다.
글을 반복해서 쓰는 용도에서 이 비용이 도입 자체를 막습니다.

Blogsmith는 실행 가능한 코드가 아니라 **AI 에이전트가 읽고 따라가는 작업 환경**입니다.
로직이 마크다운 문서로 되어 있고, 이미 구독 중인 Claude Code 안에서 돌아갑니다.
추가 비용이 없고, 문체나 SEO 전략이 마음에 안 들면 문서를 고쳐서 자기 것으로 만들 수 있습니다.

## 하려는 것

- **문체 학습**: 참고할 블로그 주소를 주면 문장 길이, 어미, 소제목 배치, 사진과 글의 비율,
  도입부와 마무리 습관을 분석해 규칙 문서로 만듭니다. 여러 개 저장하고 골라 씁니다.
- **소스 기반 생성**: 사진과 메모를 넣으면 그것만을 원천으로 씁니다. 지어내지 않습니다.
- **플랫폼별 포맷**: 네이버, 티스토리, velog는 문법과 이미지 처리가 다릅니다. 각각에 맞춰 출력합니다.
- **검색 노출 대응**: 네이버 C-Rank와 D.I.A.+, 구글 SEO, AI 검색 인용(GEO)은 서로 다른 규칙입니다.
  하나로 뭉뚱그리지 않고 나눠서 다룹니다.

## 설치

```
/plugin marketplace add Jeong-jj/blogsmith-harness
/plugin install blogsmith@jj-tools
```

작업할 디렉토리에서 초기화합니다.

```
/blogsmith:init
```

```
├── blog.config.json     기본 문체, 플랫폼, 사진 처리 방식
├── sources/             입력: 사진과 메모
├── styles/              학습한 문체 문서
└── output/              완성 아티클
```

`sources/_sample/notes.md`에 입력 형식 예시가 들어 있습니다.
문장을 다듬을 필요는 없고, 겪은 일과 사실 정보를 순서 없이 적으면 됩니다.

## 사진

**파일명이 아티클에 쓰입니다.** 사진 설명을 만드는 재료가 되기 때문입니다.
`IMG_4821.jpg`보다 `01_외관_간판작음.jpg`가 낫습니다.

아이폰에서 옮긴 `.HEIC`는 그대로 두셔도 됩니다. blogsmith가 JPG로 바꿉니다.

사진을 직접 열어볼지는 `blog.config.json`의 `imageMode`로 정합니다.
기본값 `filename`은 파일명과 메모만 보고, `read`는 사진을 실제로 읽습니다.
`read`는 장당 토큰을 꽤 쓰므로 메뉴판 가격처럼 사진 안의 정보가 필요할 때만 쓰세요.

**blogsmith는 사진을 블로그에 올리지 못합니다.**
네이버, 티스토리, velog 모두 에디터에 로그인해서 올려야 합니다.
대신 어느 자리에 어떤 사진이 들어가는지 표시하고 캡션 문구를 만들어 둡니다.

## 개발 상태

`0.1.0`. 작업공간 초기화까지 동작합니다.

| 기능 | 상태 |
|---|---|
| `init` 작업공간 초기화 | 동작 |
| `learn-style` 문체 학습 | 작성됨, 실사용 검증 전 |
| 검색 노출 지식 (네이버, 구글, AI 인용) | 작성됨 |
| 문체 자연화 (AI 티 제거) | 작성됨 |
| `write` 아티클 작성 | 미구현 |
| 플랫폼별 포맷 변환 | 미구현 |

## 문체 학습에 대해

`learn-style`은 사용자가 지정한 글 주소를 읽어 문체 규칙을 뽑아냅니다.
알아두시면 좋을 것이 세 가지 있습니다.

**읽는 범위가 좁습니다.** 한 번에 최대 6개 주소만 읽습니다.
링크를 따라가지 않고, 목록을 훑지 않습니다. 사용자가 준 주소만 봅니다.

**원문을 저장하지 않습니다.** 문체 문서에 남는 것은 규칙과 짧은 근거 발췌입니다.
발췌에는 출처 주소를 함께 적습니다. 학습 데이터로 쓰지 않습니다.

**신분을 밝히고 요청합니다.** 브라우저인 척하지 않습니다.

```
User-Agent: blogsmith/0.1 (+https://github.com/Jeong-jj/blogsmith-harness)
```

받아주면 쓰고, 막으면 물러납니다. `User-Agent`를 바꿔가며 재시도하지 않습니다.
막혔을 때는 본문을 복사하거나 캡처해서 넣는 방법을 안내합니다.

**직접 넣는 경우 원문 파일이 `styles/_raw/`에 남습니다.**
자동 수집은 처리하고 버리지만 이쪽은 복제본이 생깁니다.

- 본인이 쓴 글이라면 마음껏 쓰세요
- 다른 사람의 글이라면 문체 분석에만 쓰고, 끝나면 `styles/_raw/`를 지우세요
  `learn-style`이 분석을 마치면 삭제할지 물어봅니다

다른 사람의 글을 복사해 보관하는 데 따르는 책임은 사용자에게 있습니다.

플랫폼별 방침과 근거는
[domains.md](plugins/blogsmith/skills/learn-style/domains.md)에 정리해 뒀습니다.

## 책임

**문체는 저작권 보호 대상이 아니지만, 문장은 다릅니다.**
blogsmith가 만드는 것은 "이렇게 쓴다"는 규칙이지 남의 문장이 아닙니다.
그래도 결과물을 발행하기 전에 직접 읽고 판단하세요.

이 도구를 쓰면서 생기는 일의 책임은 사용자에게 있습니다.

- 읽어도 되는 글인지 판단하는 것
- 다른 사람의 글 원문을 보관하지 않는 것
- 대량 수집이나 서버에 부담을 주는 사용을 하지 않는 것
- 플랫폼의 이용약관을 지키는 것
- 발행하는 글의 내용에 대한 책임

제작자는 이 도구의 오용이나 그로 인한 결과에 책임지지 않습니다.
