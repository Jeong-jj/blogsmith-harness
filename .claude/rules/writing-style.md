# 문서 작성 규칙

이 레포의 모든 마크다운(README, ADR, SKILL.md, 가이드)에 적용한다.
목표는 사람이 쓴 것처럼 읽히는 문서다.

## 금지

| 대상 | 대신 |
|---|---|
| em dash `—` | 쉼표, 콜론, 괄호, 또는 문장을 끊는다 |
| 번역투: `~에 대한`, `~에 있어서`, `~을 통해`, `~로 인해` | `~의`, `~에서`, `~로`, `~때문에` |
| `~라고 할 수 있습니다`, `~하는 것이 중요합니다` | 그냥 단정한다 |
| 명사화: `이해를 높이는 것`, `활용을 통한` | 동사로: `이해한다`, `활용해서` |
| 피동: `~되어집니다`, `~라고 여겨집니다` | 능동으로 |
| 과장 형용사: 놀라운, 강력한, 혁신적인, 획기적인 | 뺀다. 근거 수치로 대체 |
| 메타 화법: `이 글에서는 ~를 살펴보겠습니다` | 본론부터 쓴다 |
| 마무리 상투구: `결론적으로`, `정리하자면` | 마지막 문단이면 안 써도 안다 |
| 이모지 소제목 | 텍스트 소제목 |

## 리듬

- 문장 길이를 섞는다. 긴 문장 뒤에 짧은 문장.
- 항목 수를 3개로 맞추지 않는다. 2개면 2개, 5개면 5개.
- 문단마다 요약 문장을 붙이지 않는다.
- 볼드는 한 화면에 두세 개까지. 전부 강조하면 아무것도 강조되지 않는다.

## 넣을 것

- 구체적인 수치와 고유명사. `상당히 빠르다`가 아니라 `200줄`
- 판단의 근거. 무엇을 포기했는지까지
- 실패하거나 막힌 지점. 잘 된 것만 쓰면 신뢰가 떨어진다

## 검사법

쓰고 나서 소리 내어 읽는다. 입에 안 붙는 문장이 번역투다.
