# examples

실제로 만든 입력과 결과물을 남기는 곳입니다.

```
examples/
└── 001-<주제>/
    ├── style/
    │   ├── _raw/      문체 학습에 쓴 원문
    │   └── style.md   learn-style 이 만든 문체 문서
    ├── sources/       write 입력으로 쓴 사진과 메모
    ├── output/        플랫폼별 결과물
    └── expected.md    이 예시의 고정값
```

**문체 문서를 결과만 두지 않고 원문과 함께 둔다.** 문체 문서는 관찰에서 나오는 것이라
결과만 있으면 그 규칙이 어디서 왔는지 확인할 방법이 없다.
원문이 있으면 회귀에서 `learn-style` 도 돌려볼 수 있다.

두 가지 목적입니다.

- 처음 온 사람이 저장소를 클론하지 않고도 무엇이 나오는지 봅니다
- 스킬을 고칠 때마다 여기로 돌려서 결과가 나빠지지 않았는지 확인합니다

`plugins/blogsmith/skills/init/template/`과 혼동하지 마세요.
그쪽은 `/blogsmith:init`이 사용자 디렉토리로 복사하는 빈 뼈대이고,
여기는 채워진 결과물입니다.

`write` 스킬이 나오면 채웁니다.
