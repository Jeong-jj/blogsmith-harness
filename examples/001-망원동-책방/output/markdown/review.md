## 스크립트로 안 되는 검사

`audit.py` 가 판정하지 못해 읽고 판단한 항목입니다.

- 소리 내어 읽기: 걸리는 곳 없습니다. `~에 대한` `~을 통해` 같은 번역투가 없습니다
- 형용사 지워보기: 과장 형용사가 없습니다. `무난하다` 는 같이 간 사람이 한 말이라 그대로 뒀습니다
- 첫 문단의 숫자와 고유명사: `활자와 자몽`, `망원동 포은로`, `망원역 2번 출구`, `오후 네 시`, `육 분` 이 있습니다
- 견해와 단점: 자몽차 단맛과 주인 응대에 견해를 적었고, 마지막 절 전체가 단점입니다
- 문단마다 요약 문장: 없습니다. 문단이 대상 하나를 말하고 끝납니다
- 경험 서술의 근거: 두 번 지나친 것, 한 자리만 비어 있던 것, 지하에 내려가 본 것 전부 notes.md 에 있습니다

## 문체 재현

문체: example-style

- [x] 필수 규칙 1~10 전부 적용
- [x] 문단 첫 문장을 합니다체로 시작한 곳 0회 (규칙 1)
- [x] 마지막 소제목이 단점 절이고 둘째 덩이를 `그리고` 로 열었습니다 (규칙 6)
- [x] `또 갈 것 같아요.` 단독 문단으로 닫고 조각 하나를 붙였습니다 (규칙 8)
- [x] 플랫폼 종속 규칙 `그 외` 적용: 소제목 `##` 한 단계, 사진 두 장을 빈 줄 없이 연달아 둠, 지도 카드 없음, 보이는 캡션 없음
- [ ] 규칙 17 괄호 혼잣말: 1회 (관찰은 편당 2~3회)

문체는 마크다운 계열에서 캡션을 쓰지 않게 하는데 `alt` 는 채웠습니다.
`alt` 는 화면에 보이지 않아 보이는 캡션이 아니고, `google-seo` 가 요구하는 항목이라
문체와 부딪히지 않습니다.

## 못 지킨 것

```
[소스 부족] 사진 묶음 수. 5묶음 (관찰은 편당 7~9묶음, 8~11장)
   사진이 6장뿐이라 두 관찰이 동시에 안 맞습니다.
   1장 묶음 비율을 먼저 맞춰 1장 넷, 2장 하나로 80%를 만들고
   묶음 수가 하한에 못 미치는 쪽을 받았습니다.
   사진이 더 있으시면 묶음을 늘릴 수 있습니다.

[소스 부족] 괄호 혼잣말 1회. 관찰은 편당 2~3회
   문단 끝에 붙일 혼잣말을 notes.md 안에서 하나(`열 평쯤`)밖에 못 찾았습니다.
   나머지는 지어내야 해서 넣지 않았습니다.

[소스 부족] 사진 없는 문단이 관찰보다 많음
   관찰은 편당 4문단인데 이 글은 8문단입니다. 사진 6장으로는 문단마다 못 붙입니다.

[판단 필요] `망원역 2번 출구` 의 아라비아 숫자
   관찰상 본문의 아라비아 숫자는 금액 한 종류뿐입니다.
   출구 번호는 거리나 개수가 아니라 명칭이라 한글 수사로 바꾸면 뜻이 깨져 그대로 뒀습니다.
   빼는 쪽이 좋으시면 `망원역에서 걸어서 육 분 정도` 로 고치겠습니다.

[판단 필요] 기준 시점을 본문에 안 적음
   `geo-aeo` 는 바뀔 수 있는 값에 `2026년 9월 기준` 을 붙이라고 합니다.
   가격, 영업시간, 대관료가 여기 해당합니다.
   문체 관찰의 도입부가 전부 상대 시점(`지난달에`)이고 날짜를 박은 예가 없어
   본문에는 `토요일 오후 네 시쯤` 만 넣고 meta.md 의 발행 전 확인으로 넘겼습니다.
   notes.md 에 2026년 9월 12일이 있으니 넣으라고 하시면 도입에 넣겠습니다.

[판단 필요] 저자 정보가 본문에 없음
   `google-seo` 의 첫 질문이 `누가 썼는가` 인데 문체에 자기소개 습관이 없습니다.
   티스토리나 velog 는 프로필이 페이지에 붙으므로 본문에 넣지 않았습니다.
   개인 도메인으로 내신다면 저자 표시를 따로 두셔야 합니다.
```
