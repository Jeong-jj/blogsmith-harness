# 검수

플랫폼을 `naver` 에서 `markdown` 으로 바꾼 재실행입니다.
본문 문장은 그대로 두고 플랫폼이 정하는 자리만 손댔습니다. 바꾼 것은 아래 네 가지입니다.

- frontmatter `platform` 을 `markdown` 으로
- 사진 여섯 장에 `alt` 를 채움 (naver 판은 비어 있었습니다)
- 영업시간 문단에 기준 시점 한 조각 추가
- `photos.md` 와 `meta.md` 의 발행 안내를 마크다운용으로 교체

## 스크립트로 안 되는 검사

- 소리 내어 읽기: 걸리는 곳 없음. 번역투 표현이 나오지 않았습니다
- 형용사 지워보기: 지워도 뜻이 남는 형용사가 없습니다.
  `좁다` 는 `열 평쯤` 이, `인기` 는 `두 개뿐` 과 `열두 자리` 가 근거를 대고 있습니다
- 첫 문단의 숫자와 고유명사: `망원동`, `활자와 자몽`, `망원역`, `네 시`, `육 분` 이 있습니다
- 견해와 단점: `저는 이 쪽이 편했어요`, `책 사러 가는 곳이지 작업하러 가는 데는 아니에요`,
  주차 불가와 콘센트 한 자리를 적었습니다
- 문단마다 요약 문장: 없습니다. 문단 끝이 다음 대상으로 넘어가거나 괄호 혼잣말로 닫힙니다
- 경험 서술의 근거: 두 번 지나친 것, 창가 한 자리가 차 있던 것, 지하에 내려가 본 것,
  자몽차 알갱이가 전부 `notes.md` 에 있습니다

## 소스에 없어서 비워둔 것

없습니다. `notes.md` 의 항목을 전부 썼습니다.

사진에서 읽어낸 값이 있습니다. `05_가격표.jpeg` 에 `[읽기]` 가 붙어 있어 열었고
`notes.md` 에 없던 네 가지가 나왔습니다.

  레몬차 6,500원 / 카페라떼 5,500원 / 초코쿠키 3,000원 / 치즈케이크 5,500원

본문의 가격 문단에 넣었습니다. 메뉴가 바뀌었으면 알려주세요.

## 문체 재현

- [x] 필수 규칙 1~10 전부 적용
- [x] 플랫폼 종속 규칙 `그 외` 쪽 전부 적용
  (소제목 `##` 한 단계, 사진 두 장을 빈 줄 없이 연달아, 캡션 없음, 지도 없음, 구분선 없음)
- [ ] 규칙 12 소제목 바로 뒤 사진: `걸렸던 것` 섹션에만 못 지켰습니다

## 못 지킨 것

```
[사진] 사진 묶음 5개 (문체 관찰 하한 7개)
   소스가 6장뿐이라 묶음 수를 못 채웠습니다.
   묶음 크기 비율(1장 80%, 2장 20%)을 먼저 맞추고 묶음 수를 역산했습니다.
   1장 네 묶음과 2장 한 묶음으로 1장 비율이 80%가 되어 관찰과 일치합니다.
   이 책방 사진을 더 갖고 계시면 넣어서 다시 돌릴 수 있습니다.

[사진] 규칙 12 소제목 바로 뒤 사진, `걸렸던 것` 섹션 1건
   같은 이유입니다. 단점 섹션에 붙일 만한 사진이 소스에 없기도 합니다.

[구조] geo-aeo 의 소제목 질문형 권고
   `앉은 자리` `시킨 것` `걸렸던 것` 은 질문형이 아닙니다.
   문체 관찰이 소제목을 문장부호 없는 2~8자 구로 못박고 있어
   질문형으로 바꾸면 네 개 중 세 개가 문체를 벗어납니다.
   `첫 번째 원칙` 대로 문체를 따랐습니다.
   AI 인용을 우선하시면 소제목만 질문형으로 바꿔드리겠습니다.

[구체성] audit.py 구체성 1건
   지적된 세 덩어리는 `망원동 책방 활자와 자몽`, `망원역`, `네 시`, `육 분`,
   `열 평`, `한 칸` 을 담고 있습니다. 전부 고유명사이거나 한글 수사입니다.
   audit.py 가 숫자와 로마자로만 세기 때문에 못 잡은 오탐입니다.
   문체 규칙 9가 금액이 아닌 수를 한글로 쓰라고 정하고 있어 숫자로 바꿀 수 없습니다.
   문체 문서를 따랐습니다.

[분량] 743자
   구글은 선호 단어 수가 없다고 명시했으므로 이 자체는 문제가 아닙니다.
   문체 관찰이 편당 본문 문단 12~13개, 평균 문장 23자이고
   14문단 38문장으로 관찰 범위 안에 있습니다.
   소스도 여기까지라 채우려고 늘리지 않았습니다.
   google-seo 가 `특정 단어 수를 목표로 작성` 을 경고 신호로 꼽은 자리입니다.

[정보] 망원역 출구 번호를 뺐습니다
   `notes.md` 에 `망원역 2번 출구` 가 있는데 본문에는 `망원역에서 걸어서 육 분` 으로만 썼습니다.
   문체 규칙 9가 금액이 아닌 아라비아 숫자를 금지하는데
   `이번 출구` 로 풀어쓰면 한국어로 어색합니다.
   geo-aeo 는 구체적인 숫자가 인용률을 41% 올린다고 보고합니다.
   문체보다 정보를 택하시면 그 자리에 다시 넣어드리겠습니다.
```
